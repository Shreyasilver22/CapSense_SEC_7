# Standalone CapSense phase-generator testbench

Open `./open_xschem.sh`. Run `python3 run_testbench.py` for RTL tests, Xschem netlisting and actual ngspice/Icarus co-simulation. The amplifier is not included or modified.

The original RTL is copied unchanged. Inputs are the requested 1 MHz clock and active-low reset, both 0–5 V. Explicit ADC models translate the two voltage inputs into digital nodes; seven DAC models translate all RTL outputs into 0–5 V voltage nets. These are simulation interfaces, not added ASIC circuits.

The source output order is phi1, phit, phi2, phi1b, phitb, phi2b, sample_valid. The symbol visually interleaves complementary phases while its netlist follows the source ordering.

## Runtime repair

Installed ivlng.so and ivlng.vpi export no functional co-simulation entry points. The installed bridge fails with missing Cosim_setup, and no libvvp runtime was found. Project-local replacements are built under runtime/. All models use explicit absolute library paths; system tools and PDKs are unchanged.

Private source commits and RTL SHA256 are in simulation/provenance.json. Build prerequisites were downloaded as Ubuntu packages and extracted into runtime-src/tools, without installing packages. Compiler source: official steveicarus/iverilog repository. Bridge source: official SourceForge ngspice repository; its cosim.h matches the installed ngspice interface. Build scripts and logs are retained. This runtime is a development-source build and must be validated before production use.

Official runtime documentation: https://steveicarus.github.io/iverilog/usage/vvp_library.html

## Verified result

PASS: actual ngspice/Icarus co-simulation for 305 us. All seven output waveforms were checked against the RTL windows, including complements and 0/5 V levels. Results are in simulation/verification.json. phi1 rises near 2.004 us, falls near 43.004 us and repeats at 102.004 us. phit rises near 47.004 us, phi2 near 48.004 us, sample_valid near 82.004 us for approximately 1 us. Frame period is 100 us.

Two additional issues were corrected during verification:

* ngspice lowercased mixed-case absolute library paths in the model card. Runtime paths in models.spice are now relative to the simulation working directory. Always use run_testbench.py or launch ngspice from simulation/.
* A 1.5–3.5 V ADC threshold band produced intermediate digital X values and extra Verilog clock events during transitions. For these ideal clock/reset sources, the input ADC now uses one 2.5 V threshold (in_low=in_high=2.5). Physical input buffering/hysteresis is not modeled.

The specified reset release and 2-us clock edge coincide; the first active count in this tested setup is near 2 us, not 3 us. Robust ASIC reset deassertion must meet clock recovery/removal requirements; this is a separate integration requirement. No RTL changes were made.

The private Icarus executable needs runtime/lib on LD_LIBRARY_PATH; run_testbench.py sets it only for its child processes. No global environment is changed.

## Tests and outputs

simulation/rtl_test.log: original system Icarus test result (reset and 300 clock edges).
simulation/rtl_phases.vcd: digital-only waveform.
simulation/cosim.log and phases.dat: actual mixed-signal execution.
simulation/phases.svg: phase plot generated by ngspice.
simulation/verification.json: generated only after waveform checks pass.

A successful process exit alone does not prove co-simulation. validate_cosim.py rejects runtime errors, incomplete transients, wrong voltage levels and phase mismatches. No PULSE substitutes generate output phases.

## Next integration checks

Only after standalone validation should the main project model paths/compiler be updated to this private runtime. This bench uses ideal DAC models with 1 ns slopes and resistive test loads. It does not validate the amplifier's convergence, transistor-gate loading, switch drive or settling. Earlier analog testing encountered timestep collapse with fast edges. Gate slew and real buffers require separate investigation; no timing or analog-device changes are made here. Auxiliary precharge/track/CM/ADC clocks in the other analog project are not generated by this seven-output RTL.

If this folder moves, update absolute paths in xschemrc and schematic references. Runtime/model paths are relative to simulation/.
