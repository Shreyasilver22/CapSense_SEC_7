# Grounded TX / RX capacitance grid

This ngspice bench uses the current SCL08 switched-capacitor readout, transistor-level 10 kHz clock and trim, reference buffer and OTA bias generator. TX charges to 5 V, then discharges to 0 V. RX clamps to 0 V during precharge. The OTA common-mode setpoint and hold-capacitor precharge remain 2.5 V. Model settings are typical SCL08, 5 V, 27 °C, trim code 3 and nominal OTA bias. Each branch uses the existing 121-device PMOS feedback bank and a 10 pF hold capacitor. The two input capacitors are ideal fixed values within each run.

Each of CP and CN is independently swept from 1 through 15 pF in 1 pF steps, giving 225 combinations. Common-mode is the average of each differential node pair. Transfer extrema use 40–70 µs of the first cycle, tracking extrema use 69.7–80.0 µs and held values are read at 81 µs. Simulations end at 83 µs. The low input common-mode contour is the prior 1.5 V standalone OTA design point, used as a headroom guide.

From this directory, run `python3 sweep.py /tmp/capsense_ground_grid --fine-grid --resume` and `python3 plot.py /tmp/capsense_ground_grid/results.csv`. The initial screening run normally uses a maximum step of 120 ns. The fine grid uses KLU and trapezoidal integration at a maximum step of 40 ns, with alternate solver and step settings available on retry. The script derives each deck from the parent integrated bias testbench. Per-case columns record the solver and step actually used. Logs and binary raw waveforms are written to the specified working directory. The brief common-mode minima around RX turn-on are sensitive to simulation timestep. Compare the 81 µs values separately. These are nominal first-cycle electrical simulations.

`results.csv` contains all 225 successful 40 ns runs. In this grid, the OTA input common-mode at 81 µs spans 0.770–2.346 V and is below 1.5 V for all 120 pairs with CP + CN of at least 16 pF. Held output common-mode spans 2.476–2.501 V. Rechecks at 10 ns for 12/7 pF and 15/15 pF are recorded in `timestep_checks.csv` and shown in the waveform plot. At 15/15 pF, the 10 ns run reaches 0.497 V input common-mode at 49.302 µs. The shorter RX turn-on checks are in `rx_edge_checks.csv`.
